# 你是哪种职场生存人格？

一个可直接运行的中文 H5 趣味测试产品。

## 已包含

- 19 道原创职场情境题
- 8 种原创人格结果：谋局型、冲锋型、守边型、搭桥型、潜伏型、救火型、破局型、稳进型
- 结果维度条、结果长图下载、结果文案复制
- 本地答题进度保存，刷新后可继续
- 响应式移动端布局与键盘焦点样式
- 适合接入小红书商品链接的低门槛数字产品结构

## 本地运行

在当前目录执行：

```bash
python3 -m http.server 45123 --directory outputs/workplace-persona
```

然后打开 `http://127.0.0.1:45123/`。

## 交付说明

产品定位是趣味自我观察，不是心理诊断、职业诊断或重大决策工具。所有题目、人格命名和视觉文案均为本产品原创。
